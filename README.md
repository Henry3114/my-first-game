# 麦间 · 街角烘焙日记

一款可直接游玩的中文单人网页经营游戏。没有强制引导，从第一天自由经营自己的街角烘焙店。

## 发布到 GitHub Pages

本仓库已包含可直接托管的 index.html 和 .nojekyll。把代码推送到 main 后，在仓库 **Settings → Pages** 中将 Source 设为 **Deploy from a branch**，选择 **main** 分支、**/ (root)** 目录，点击 Save。

GitHub 完成部署后，访问地址为 `https://henry3114.github.io/my-first-game/`。启用和构建成功前，此地址可能无法访问；以 Pages 设置中显示的部署状态为准。以后更新源码，先运行 `npm run build`，连同生成的 index.html 一起推送。

## 运行

直接下载或打开仓库根目录的 **index.html** 即可游玩。它已包含脚本、样式和插画，不需要服务器，也不依赖外部网络。网页预览同样使用这个入口。

开发时也可启动本地服务，需要 Python 3，无需安装运行依赖。在仓库目录执行：

```sh
npm start
# 或
python3 -m http.server 8000 --bind 0.0.0.0
```

用浏览器打开服务的 8000 端口。

修改源码后运行 `npm run build`，将 game.js、art.js、app.js、styles.css 与 assets/ 重新打包到 index.html。HTML 骨架在 scripts/page.html。请修改源文件，再生成入口，避免生成文件与源码不一致。

## 玩法

- 点“烤一炉”准备面包，每炉六份，食材费用在入炉时扣除。
- 点“开始营业”，顾客自动选购。09:00–18:00 约 108 秒，可随时暂停、补烤、促销或提前打烊。
- 营业场景是可点击的店铺内景。顾客会从店门走入、挑选、在柜台等待、付款，再提着纸袋离开；场景人物和真实交易一一对应。面包架中的商品随库存变化。
- 点击人物或场景下方的姓名切换对话。“热情招呼”会让成交客人给 ¥2 小费，熟客还会增加好感；“请等一炉”可延长一次等待；缺货时可推荐现有产品，再点“打包结账”。不操作时，顾客会在等待结束后自动购买，缺货且未接受替代品则离店。
- 开门前烤箱仍运行，店内时钟不会前进。后台标签页和弹窗会暂停计时；离线不会消耗面包或现金。
- 每天有一份街坊预订和营业额心愿。天气、周末、招牌升级影响客流，熟客有各自偏好与关系进展。
- 用营业积累研发六款产品、扩充烤箱和陈列位、升级招牌、雇用帮手，也可免费更换门面配色。
- 打烊时食材费用不会重复扣除；待烤批次计入余量，剩余产品按单价向下取整的 25% 折价回收。水电 ¥8/天，帮手工资 ¥25/天。升级和研发属于投资，不计入营业结余。
- 经营困难时，下一天提供街坊互助金，避免无法再生产的死档。

## 存档

自动存档使用浏览器 localStorage，不同浏览器、域名、端口和设备不共享进度。设置中可导出 JSON 备份、导入存档或重新开始。清理浏览器数据前请先导出存档。

## 验证

需要 Node.js 18 或更新版本，无需安装测试依赖：

```sh
npm test
```

测试覆盖生产、库存容量、收款、预订、结算、升级、研发、暂停、存档校验、顾客完整行程、对话选择的经济效果和连续 30 天经营。

浏览器集成测试需要安装开发依赖和 Chromium（当前云环境已具备）：

```sh
npm ci --cache /tmp/maijian-npm-cache
# 没有系统 Chromium 时，先执行 npx playwright install chromium
npm run test:ui
```

测试会自行启动临时 HTTP 服务，覆盖完整营业日、暂停、升级、刷新恢复、存档导入导出、人物交互、画布跨更新保留、旧存档迁移和手机布局；截图保存在忽略的 test-results/ 目录。live-customers.png 是顾客实际成交的截图。可用 CHROMIUM_PATH 指定浏览器路径。

项目使用原生 HTML / CSS / JavaScript，不依赖外部字体、图片或 CDN。game.js 是经营引擎，app.js 负责界面与存档，scene.js 是独立的 Canvas 2D 场景渲染器，scene.css 是场景和对话样式，art.js 和 assets/ 提供 SVG 插画。修改这些源码后均需运行 npm run build。index.html 是可独立分发的完整游戏；浏览器禁用存储时仍可游玩，但应导出存档备份。

v1.1 保持原先的存档键和格式，旧存档会保留零钱、天数、配方、设备与熟客关系；只为旧存档补上当前店内顾客列表，不会重置游戏。重新载入时不重复收取已付款客人的费用。动画在暂停和后台标签页时停止，支持减少动态效果的系统偏好。
